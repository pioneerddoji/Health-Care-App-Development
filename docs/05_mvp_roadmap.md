# 5. MVP 개발 순서

각 단계는 "그 단계만으로 데모 가능"을 기준으로 자른다. 총 6주 가정(1인 기준, 조정 가능).

## 0단계 — 프로젝트 골격 (본 저장소에 포함, 완료)
- Expo + TypeScript 스캐폴드, 네비게이션, 디자인 토큰
- 도메인 타입/상수(기록 12종, 영역 14종), 샘플 데이터, 인메모리 저장(AppContext)
- 기본 UI 전 화면, 차트 컴포넌트, PDF 생성

## 1단계 — 기록 루프 (1.5주) ✅ 사진 첨부 완료
- ✅ 사진 첨부(expo-image-picker): 기록 폼 선택/삭제, 목록 썸네일, PDF 임베드
- RecordForm 입력 폼 고도화(시간 선택 휠, 숫자 키패드 최적화) — 잔여
- 영역 태그 자동 제안 + 수정 UX ✅

## 2단계 — Supabase 연동 (1.5주) ✅ 완료
- ✅ Auth(이메일 가입/로그인/세션 복원), profiles 생성
- ✅ 저장소 계층(repo) 도입: 인메모리/Supabase 구현 교체 가능 (화면 무변경)
- ✅ Storage 업로드(record-files) + 서명 URL, 버킷/정책 schema.sql 포함
- ✅ 아이 생성 시 consents(법정대리인+민감정보) 기록 — RLS가 미동의 기록을 차단
- 잔여: RLS 통합 테스트 자동화, Storage 파일 삭제 배치

## 3단계 — 공동 관리 + 다자녀 (1주) ✅ 완료
- ✅ 보호자 초대(이메일, invite_guardian RPC) → guardian_child 생성, 역할 변경/해제
- ✅ viewer 읽기전용 UI 처리 (기록/프로필/접종/삭제 차단 + 안내)
- ✅ 아이 전환 UX (기록/대시보드/레포트 탭 상단 ChildSwitcher)
- ✅ guardian_child RLS 정책 강화 (schema_stage3.sql — 자기승격/임의삽입 차단)
- ✅ RLS 통합 테스트로 2계정 시나리오 검증(로컬 PostgreSQL) — 실 Supabase 프로젝트
  연결 후 동일 시나리오 1회 재확인은 남음. 소유권 이전은 비범위→백로그.

## 4단계 — 레포트/공유 (1주) ✅ 완료
- ✅ PDF 업로드(Storage `reports` 버킷) + `reports` 행 발행, 레포트 탭에서 기간·질문과 함께 생성
- ✅ 만료형 공유 링크 생성/회수 — Edge Function(`share-report`)이 매 접속마다
  만료·회수를 재검사한 뒤 짧은 수명 서명 URL을 새로 발급(진짜 회수 가능),
  설정 화면에서 아이별 링크 목록·상태·회수 관리
- ✅ 예방접종/건강검진 예정일 로컬 알림(expo-notifications) — 등록/수정 시 자동 예약,
  완료 처리 시 자동 취소
- 잔여: Edge Function 실제 배포·수신자 관점 테스트(실 프로젝트 필요), 알림 권한 거부 후
  재안내 UX

## 5단계 — 마감 품질 (1주) ✅ 핵심 완료
- ✅ 데이터 완전 삭제: Storage 사진/PDF까지 재귀 삭제 후 DB cascade (배치 불필요해짐)
- ✅ 동의 철회/재동의 UI (설정 → 동의 내역) — 철회 시 기록 입력 즉시 차단(RLS 39건 테스트)
- ✅ 개인정보처리방침: 앱 내 화면 + 웹 게시용 초안(`docs/privacy_policy.md`) — 법률 검토 필요
- ✅ 알림 권한 거부 시 안내 배너 + 기기 설정 열기
- ✅ E2E 스모크 플로우(`maestro/smoke.yaml`) — 실기기/에뮬레이터 실행은 남음
- 잔여: 접근성/카피 정리, 온보딩 다듬기

## 6단계 — 배포 준비 ✅ 저장소 측 완료 (계정 작업은 체크리스트로)
- ✅ EAS 빌드 프로파일(`eas.json`), 앱 아이콘/스플래시 임시 시안, app.json 프로덕션 설정
- ✅ Supabase 연결 검증 스크립트(`npm run verify:supabase`) — 실 프로젝트 1회 스모크
- ✅ CI(GitHub Actions): 타입체크 + RLS 39건 회귀 테스트
- ✅ 개인정보처리방침 웹 게시본(`docs/privacy_policy.html`)
- ✅ 배포 가이드 + 계정 소유자 체크리스트(`docs/06_deployment.md`)
- 잔여(계정 필요): Supabase 운영 프로젝트, 번들 ID 확정, Apple/Google 계정,
  실기기 테스트, 방침 법률 검토, 심사 제출

## 7단계 — 수익화(3티어 구독) ✅ 완료 (결제 SDK 연동 제외)
- ✅ 무료/스탠다드/패밀리 티어 정의 + 페이월 화면 + 화면별 게이팅(🔒)
- ✅ 서버 강제: 아이 수(트리거)·공동 보호자 수(RPC), subscriptions 테이블(웹훅 전용 쓰기)
- ✅ RLS 44건 + 게이팅 스모크 12건 통과
- 잔여: RevenueCat/스토어 상품 등록 + 웹훅 Edge Function (스토어 계정 필요, docs/07)

## 명시적 비범위 (MVP 제외)
- 성장 백분위 곡선(질병청 표준 데이터 연동) — 2차
- AI 자연어 기록 정리/레포트 요약 — 2차 (범위: 정리·태그·요약까지만)
- 진단 추정, 약 용량 추천, "병원 안 가도 됨" 판단 — **영구 비범위**
