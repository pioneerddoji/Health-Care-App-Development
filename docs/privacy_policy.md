# 아이케어 개인정보처리방침 (v0.1 초안)

시행일: 2026-07-10 — **정식 배포 전 법률 검토 필요.** 스토어 등록 시 이 문서를
웹페이지로 게시하고 URL을 제출한다. 앱 내 표시는 `src/screens/settings/PrivacyPolicyScreen.tsx`.

## 1. 수집하는 개인정보와 수집 목적
- 보호자 계정: 이메일, 이름, 아이와의 관계, 연락처(선택)
- 아이 인적사항: 이름, 별명, 생년월일, 성별, 출생정보(체중·재태주수), 혈액형
- 건강 기록(보호자 직접 입력): 증상, 체온, 식사, 수면, 배변, 운동, 복용약,
  알레르기, 만성질환, 수술/입원 이력, 예방접종/검진, 첨부 사진
- 목적: ① 기록 저장·조회 ② 기간별 그래프 시각화 ③ 병원 제출용 레포트 생성
  ④ 보호자 공동 관리 ⑤ 접종·검진 예정일 알림 — 이외 목적으로 사용하지 않는다.

## 2. 민감정보의 처리
아이의 건강 기록은 개인정보 보호법 제23조의 민감정보다. 회원가입 시 **별도 동의**를
받으며, 동의 철회 시 새 기록 입력이 즉시 중단된다(설정 → 동의 내역, 서버 정책으로도
차단). **아이 얼굴 사진은 수집하지 않는다** — 프로필은 이모지 아바타만 사용하고,
기록 첨부 사진은 얼굴이 나오지 않게 촬영하도록 안내한다.

## 3. 만 14세 미만 아동의 개인정보
회원가입은 아동의 **법정대리인(부모 등 보호자) 본인만** 할 수 있다. 아동 개인정보
수집·이용은 가입 시 법정대리인 동의로 이루어지며, 아이 등록 시마다 해당 아이 단위의
동의 기록(consents)이 저장된다.

## 4. 보관, 위탁 및 국외 이전
데이터는 Supabase(클라우드 DB·스토리지)에 TLS 암호화 전송으로 저장된다. 사진·레포트
파일은 비공개 버킷에 저장되며 만료되는 서명 URL로만 접근된다. 프로젝트 리전에 따라
국외 보관될 수 있으며, 배포 시 이전 국가·항목·보관 기간을 확정해 고지한다.

## 5. 제3자 제공
보호자가 직접 생성한 **만료형 공유 링크**를 통해서만 레포트가 외부(의료진 등)에
전달된다. 링크는 만료 시간이 있고 언제든 회수할 수 있으며, 회수 즉시 접근이 차단된다.
그 외 제3자 제공은 없다.

## 6. 파기
아이 데이터 전체 삭제 실행 시 해당 아이의 모든 DB 기록과 Storage 파일(사진, 레포트
PDF)이 즉시 삭제된다. 계정 탈퇴 시 계정 정보와 모든 아이 데이터가 삭제된다.

## 7. 정보주체의 권리
보호자(법정대리인)는 열람·정정·삭제·처리정지(동의 철회)를 앱 내 설정 화면에서 직접
실행할 수 있다.

## 8. 의료행위 아님 고지
이 앱의 기록·그래프·레포트는 보호자의 관찰 기록이며 의학적 진단·소견·처방이 아니다.
앱은 진단명 추정, 약 용량 계산·추천, 병원 방문 필요성 판단을 수행하지 않는다.
